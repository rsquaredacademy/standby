## Patch release

This is the 0.2.2 patch release after CRAN 0.2.0 (0.2.1 was never released).
It fixes the loading-screen animations (all Three Dots types, the music and
border loaders, loader style/text combinations, SpinKit child elements),
argument validation with clear error messages, and the help pages. See NEWS.md.

* Local: Windows 11 x64, R 4.6.1 (ucrt)
* Linux x86_64 (Ubuntu): R 4.6.2 and R-devel (4.7.0)
* win-builder: R-release and R-devel
